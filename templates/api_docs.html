⚡ PYQBox REST API (v1)

High-performance JSON API serving 22,359 questions across JEE Main, JEE Advanced, and NEET UG with full shift metadata, year sorting, and LaTeX solutions.

GET /api/v1/exams

Returns all available exams, total question counts, subjects, and available years.

curl -s http://localhost:5050/api/v1/exams
GET /api/v1/chapters?exam=main&subject=physics

Returns chapters filtered by exam and subject with question counts.

curl -s "http://localhost:5050/api/v1/chapters?exam=main&subject=physics"
GET /api/v1/papers?exam=main&year=2026

Returns all 270 official papers & shifts with question counts and slugs.

curl -s "http://localhost:5050/api/v1/papers?exam=main&year=2026"
GET /api/v1/questions?exam=main&chapter=alternating-current&sort=year_desc&limit=10

Paginated questions with sorting (sort=year_desc / sort=year_asc) and filters (year, shift, paper, type).

curl -s "http://localhost:5050/api/v1/questions?exam=main&year=2026&sort=year_desc&limit=5"
GET /api/v1/questions/:id

Returns full question payload including clean LaTeX options, diagrams, correct answer, and worked solution.

curl -s "http://localhost:5050/api/v1/questions/0928dd2e-7799-4199-8e1c-1e07132db37e"
POST /api/v1/check-answer

Verifies student option or numerical answer against correct key and returns worked solution.

curl -X POST http://localhost:5050/api/v1/check-answer -H "Content-Type: application/json" -d '{"question_id": "0928dd2e-7799-4199-8e1c-1e07132db37e", "selected_answer": "A"}'
GET /api/v1/search?q=inductance

FTS5 indexed search querying across 22,359 questions in <10ms.

curl -s "http://localhost:5050/api/v1/search?q=capacitor"
